# 3D Game Engine Project

This project is a **custom 3D game engine** written in C++ using OpenGL. It supports rendering terrain, water, lighting, skyboxes, and GUI elements. The engine includes shaders, textures, collision detection, and a simple entity system.

## Features

- **Terrain**: Height map-based terrain with multi-texturing and collision detection.
- **Water**: Water rendering with normal maps, reflection, refraction, and culling plane support.
- **Lighting**: Point lights and dynamic day/night cycle.
- **Camera**: Free movement and mouse picking for interaction.
- **Models & Textures**: Support for raw and textured models, skyboxes.
- **Shaders**: Custom GLSL shaders for terrain, water, skybox, and GUI.
- **GUI**: Simple overlays like health bars.
- **Extras**: Resource management, object loading, and rendering optimizations.

## Dependencies

- C++ compiler (C++11 or later)
- OpenGL
- GLFW (windowing and input)
- GLEW (OpenGL extensions)
- SDL2
- libpng
- zlib
